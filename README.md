## 📌 Sobre o Projeto

A **Landing Page da Dra. Natália Coutinho** foi desenvolvida com foco em conversão, elegância visual e performance técnica extrema. O objetivo é apresentar tratamentos médicos capilares avançados de forma clara, profissional e humanizada, garantindo agendamentos diretos via WhatsApp.

O layout conta com uma seção Hero refinada, otimização milimétrica de imagens e tipografia sofisticada, adaptada perfeitamente para dispositivos móveis e desktops.

---

## ✨ Funcionalidades

- 📱 **Mobile-First & Ultra Responsivo:** Experiência fluida ajustada para smartphones, tablets e monitores de alta resolução.
- 🎯 **Foco em Conversão:** Chamadas para ação (CTAs) estratégicas para agendamento direto via WhatsApp.
- 🖼️ **Otimização de Imagens:** Posicionamento dinâmico e enquadramento ideal dos assets visuais da médica.
- ⚡ **Performance Superior:** Desenvolvido com SSR (Server-Side Rendering) e otimização nativa do Next.js.
- 🔍 **SEO Completo & Open Graph:** Configuração de metatags avançadas para compartilhamento rico no WhatsApp e redes sociais.
